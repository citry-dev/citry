# Support

Start with the [VS Code guide](https://citry.dev/ide/vscode/) for installation,
project setup, formatting, and troubleshooting.

- Ask usage questions in [GitHub Discussions](https://github.com/citry-dev/citry/discussions).
- Report reproducible bugs through the [issue chooser](https://github.com/citry-dev/citry/issues/new/choose).
- Request features through the [feature form](https://github.com/citry-dev/citry/issues/new?template=feature_request.yml).
- Report security problems privately through [GitHub Security Advisories](https://github.com/citry-dev/citry/security/advisories/new).

For extension bugs, include the Citry extension version, `citry-lsp` version,
VS Code version, operating system, selected Python interpreter, and the output
from **Citry: Show Language Server Status**. Remove secrets and private paths
from logs before posting them publicly.
