# NavigationMenu

`CNavigationMenu`, `CNavigationMenuLink`, and `CNavigationMenuItem` render
persistent website navigation with ordinary links and optional rich disclosure
panels.

The authoritative contract is
[`docs/design/ui_components/navigation-menu.md`](../../../../../../../docs/design/ui_components/navigation-menu.md).
Public usage lives in [`api.md`](api.md), and fixed reference data lives in
[`api.yml`](api.yml).
