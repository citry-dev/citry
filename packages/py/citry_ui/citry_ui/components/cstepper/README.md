# Stepper

`CStepper` renders a named ordered workflow indicator and `CStep` declares each
step. Optional interactive navigation uses native Buttons, while panels,
validation, and workflow actions stay in application composition.

The authoritative contract is
[`docs/design/ui_components/stepper.md`](../../../../../../../docs/design/ui_components/stepper.md).
Public usage lives in [`api.md`](api.md), and fixed reference data lives in
[`api.yml`](api.yml).
