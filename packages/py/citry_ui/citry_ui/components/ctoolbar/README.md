# Toolbar

`CToolbar` is the APG-style named composite for three or more persistent
controls. It owns one roving page Tab stop and orientation-aware arrow-key
navigation while each Button, Toggle, link, Menu, or Popover retains its own
action and state.

The authoritative contract is
[`docs/design/ui_components/toolbar.md`](../../../../../../../docs/design/ui_components/toolbar.md).
Public usage lives in [`api.md`](api.md), and the fixed reference projection
lives in [`api.yml`](api.yml).
