# DatePicker

`CDatePicker` composes `CPopover`, `CCalendar`, and the shared `CIcon` catalog
into a field-like popup
control while one native Date input remains its canonical Form, reset,
validity, and no-JavaScript transport.

The authoritative contract is
[`docs/design/ui_components/date-picker.md`](../../../../../../docs/design/ui_components/date-picker.md).

Use `CDateInput` for direct native editing and `CCalendar` for an always-visible
calendar.
