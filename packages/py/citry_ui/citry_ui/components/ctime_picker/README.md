# TimePicker

`CTimePicker` composes a native time transport with `CPopover` and `CListbox`
to present a bounded, locale-formatted set of wall-clock choices.

The authoritative family contract is
[`docs/design/ui_components/time.md`](../../../../../../docs/design/ui_components/time.md).

Use `CTimeInput` for open-ended platform-native editing. Neither component
represents a date, duration, instant, or time zone.
