# FileInput and DropTarget

`CFileInput` is the styled native file picker and `CDropTarget` is its
drag-and-drop alternative backed by the same native file-input and form
semantics. The family selects files but never uploads, reads, previews, or
validates their contents.

The authoritative contract is
[`docs/design/ui_components/file-input.md`](../../../../../../../docs/design/ui_components/file-input.md).
Public usage lives in [`api.md`](api.md), and the structured reference lives in
[`api.yml`](api.yml).
