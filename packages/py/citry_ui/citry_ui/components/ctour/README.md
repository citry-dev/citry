# Tour family

`CTour` and `CTourStep` render a modal, server-authored product walkthrough
with centered or exact-ID target steps. The authoritative contract is
[`docs/design/ui_components/tour.md`](../../../../../../../docs/design/ui_components/tour.md).

Public usage lives in [`api.md`](api.md), fixed reference data in
[`api.yml`](api.yml), examples in [`snippets/`](snippets/), and shared quality
evidence in [`quality/scenario.py`](quality/scenario.py).
