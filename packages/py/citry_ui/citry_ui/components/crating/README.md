# Rating

`CRating` selects or displays one exact score on a short bounded star scale.
It keeps native radio Form behavior, required validation, reset, controlled
requests, fractional precision, readonly submission, and localized choice
names.

The authoritative contract is
[`docs/design/ui_components/rating.md`](../../../../../../docs/design/ui_components/rating.md).

Use `CRadioGroup` when each choice needs its own authored label. Use `CSlider`
for a longer continuous-looking numeric scale.
