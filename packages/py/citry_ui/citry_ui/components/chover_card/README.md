# HoverCard

`CHoverCard` renders a polished, noninteractive visual preview for supplementary
content behind a focusable link or control.

The authoritative contract is
[`docs/design/ui_components/hover-card.md`](../../../../../../../docs/design/ui_components/hover-card.md).
Public usage lives in [`api.md`](api.md), and fixed reference data lives in
[`api.yml`](api.yml).
