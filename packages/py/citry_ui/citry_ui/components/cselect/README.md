# Select

`CSelect` and `CSelectOption` render a styled, progressive-enhancement,
single-value form control with a select-only combobox popup.

The authoritative contract is
[`docs/design/ui_components/select.md`](../../../../../../../docs/design/ui_components/select.md).
Public usage lives in [`api.md`](api.md), and fixed reference data lives in
[`api.yml`](api.yml).
