# Timeline family

`CTimeline` and `CTimelineItem` render semantic chronological event and
activity sequences. The authoritative contract is
[`docs/design/ui_components/timeline.md`](../../../../../../../docs/design/ui_components/timeline.md).

Public usage lives in [`api.md`](api.md), fixed reference data lives in
[`api.yml`](api.yml), executable examples live in [`snippets/`](snippets/),
and the shared qualification fixture lives in [`quality/scenario.py`](quality/scenario.py).
