# Listbox

`CListbox`, `CListboxOption`, and `CListboxGroup` render a persistent,
accessible single- or multiple-selection collection.

The authoritative contract is
[`docs/design/ui_components/listbox.md`](../../../../../../../docs/design/ui_components/listbox.md).
Public usage lives in [`api.md`](api.md), and fixed reference data lives in
[`api.yml`](api.yml).
