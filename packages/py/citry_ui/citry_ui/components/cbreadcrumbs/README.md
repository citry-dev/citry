# Breadcrumbs maintainer notes

`CBreadcrumbs` is a zero-JavaScript semantic navigation trail. Keep the native
`nav > ol > li` structure, hide separators from accessibility APIs, and treat
the final item as the current page.

The complete contract lives in
[`docs/design/ui_components/breadcrumbs.md`](../../../../../../../docs/design/ui_components/breadcrumbs.md).
