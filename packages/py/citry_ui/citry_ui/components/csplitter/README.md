# Splitter

`CSplitter` renders an accessible resizable panel group and
`CSplitterPanel` declares its named panels.

The authoritative contract is
[`docs/design/ui_components/splitter.md`](../../../../../../../docs/design/ui_components/splitter.md).
Public usage lives in [`api.md`](api.md), and fixed reference data lives in
[`api.yml`](api.yml).
