# Editable

`CEditable` turns one native text Input into a compact view-and-edit surface.
Its pencil, confirm, and cancel Buttons sit inside the Input by default;
`action_position="outside"` moves the edit actions beside it.

The authoritative contract is
[`docs/design/ui_components/editable.md`](../../../../../../../docs/design/ui_components/editable.md).
Public usage lives in [`api.md`](api.md), and fixed reference data lives in
[`api.yml`](api.yml).
