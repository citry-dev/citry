# Carousel

`CCarousel` and `CCarouselSlide` render an accessible, native-scroll content
carousel with explicit controls and optional picker indicators.

The authoritative contract is
[`docs/design/ui_components/carousel.md`](../../../../../../../docs/design/ui_components/carousel.md).
Public usage lives in [`api.md`](api.md), and fixed reference data lives in
[`api.yml`](api.yml).
