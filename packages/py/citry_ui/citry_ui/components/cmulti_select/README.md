# MultiSelect

`CMultiSelect` and `CMultiSelectOption` render a styled progressive-enhancement
multiple-value form control with a select-only combobox popup and native
`select[multiple]` form truth.

The authoritative contract is
[`docs/design/ui_components/multi-select.md`](../../../../../../../docs/design/ui_components/multi-select.md).
Public usage lives in [`api.md`](api.md), and fixed reference data lives in
[`api.yml`](api.yml).
