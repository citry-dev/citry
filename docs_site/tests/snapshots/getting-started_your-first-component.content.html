Your first component

A component in citry is a Python class. It pairs a template (the HTML you want) with a small method that prepares the values the template reads. This page walks through writing one, rendering it, and seeing the HTML it produces.

Define the component

Subclass Component and give it a template. Then override template_data to return the values the template's {{ }} expressions read.

from citry import Component

class Welcome(Component):
    template = """
      <div class="card">
        <h1>{{ title }}</h1>
        <p>You have {{ count }} new messages.</p>
      </div>
    """

    def template_data(self, kwargs, slots):
        return {
            "title": kwargs["title"],
            "count": len(kwargs["messages"]),
        }

Two things are happening here:

  • The template is the HTML the component renders. Inside it, {{ title }} and {{ count }} are expressions that read names prepared for the template.
  • template_data returns a dict of exactly those names. Whatever keys you return are the names the template can see.

Read a kwarg

When you call the class (in the next step), the keyword arguments you pass become kwargs. Here the component reads two of them, title and messages.

Because this component does not declare an inner Kwargs class, kwargs is a plain dict, so you read values with subscript access: kwargs["title"].

template_data runs as ordinary Python, so every builtin is available here. That is why len(kwargs["messages"]) works: the counting happens in template_data, and the template just displays the prepared count. Builtins like len are not available inside {{ }} expressions, so preparing the value here is the way to show a computed number.

Render it

Calling Welcome(...) does not build a component object. It returns a CitryElement, a lightweight description of what to render. You turn it into an HTML string by passing it to str().

component = Welcome(title="Welcome back", messages=["a", "b", "c"])
html = str(component)

str(component) runs the full render, then serializes the result to HTML. The output looks like this:

<div class="card" data-cid-c1="">
  <h1>Welcome back</h1>
  <p>You have 3 new messages.</p>
</div>

The data-cid-c1="" marker is added by citry to identify this rendered instance. The title shows the value you passed in, and count shows 3, the length of the three-item messages list that template_data computed.

How the pieces fit

  • template is the HTML, with {{ }} expressions marking where values go.
  • template_data(self, kwargs, slots) prepares those values. It reads the inputs from kwargs and returns a dict whose keys are the names the template reads.
  • Calling the class returns a CitryElement; str() on it produces the HTML.

If you need finer control over rendering, str(component) is a shortcut for component.render().serialize(), which accepts options. You will meet those in later pages.
