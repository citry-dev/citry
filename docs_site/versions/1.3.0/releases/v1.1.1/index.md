# v1.1.1

Citry 1.1.1 changes only the package's PyPI metadata, with no code
changes. It behaves like 1.1.0 and still requires citry-core 2.1.2.

## Changed

- PyPI now lists Citry under the Django (5.2 and 6.0), Flask, FastAPI
  and AsyncIO framework classifiers, the web development topics, and
  `Typing :: Typed`. Directories and PyPI searches can use these to
  find it.
