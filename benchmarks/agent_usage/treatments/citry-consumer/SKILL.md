Use https://citry.dev/llms.txt to locate documentation for the requested
feature. Fetch the linked Markdown guides and API references as needed.
The index points to individual pages; the full export is much larger.

Check the installed Citry version before choosing an API. When a documented
symbol is unavailable, inspect the installed public package and look for the
matching released documentation. Keep the task's pinned dependencies.

For component composition, consult the guides for inputs, slots, registration,
and rendering. For browser behavior, consult the browser setup and asset
delivery guides. For Python event handlers, also consult the web integration,
event, and state guides. Fetch the sections relevant to the requested work.

Follow a complete documented example through setup and rendering before
adapting individual calls. Verify browser features in a browser, including
independence between repeated component instances when the task requires it.
Report the commands used to verify the result and any remaining failures.
