# Storybook extension research

This directory contains the evidence for the optional Storybook extension
described in [`../extensions_storybook.md`](../extensions_storybook.md).

- [`adapter-exploration.md`](adapter-exploration.md) records the Citry UI
  Server/Webpack and HTML/Vite spike, measured behavior, and unresolved
  lifecycle constraints.

The executable spike remains in
[`packages/py/citry_ui/storybook`](../../../packages/py/citry_ui/storybook/)
until a generic extension package and API are selected.
