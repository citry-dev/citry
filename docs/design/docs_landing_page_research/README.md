# Landing-page research artifacts

This directory contains executable proofs for
[`docs_landing_page.md`](../docs_landing_page.md). The proofs answer one design
question at a time and stay outside the production documentation application.
Generated pages and local measurement runs are disposable. Reviewed evidence
may be committed when it records the environment, harness revision, and
limitations needed to interpret it.

The current proof is [`component_field_proof`](component_field_proof/README.md),
which compares literal DOM cells with a component-generated canvas projection.
